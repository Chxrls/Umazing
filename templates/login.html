Umazing Bot

Introduction

Umazing is a feature-rich Discord bot built for Uma Musume: Pretty Derby fans. It connects directly to the umapyoi.net API to deliver real-time character data, support card lookups, voice actor information, and the latest game news — all within Discord.

Designed with speed and elegance in mind, Umazing uses slash commands for an intuitive experience. Whether you're looking up your favourite uma-girl's profile, checking support card stats via GameTora, or catching up on the latest announcements — Umazing has you covered.

Built with discord.py, powered by aiohttp, and monitored through a live glassmorphism dashboard.

Features

  • /character Look up any Uma Musume character — profile, image, birthday, and more.
  • /card List support cards for a character with optional GameTora links.
  • /umavoice Find the voice actor for any character, including socials.
  • /umanews Display the 5 most recent Uma Musume news posts.
  • /play Play music in voice channels with queue management.
  • /skip Skip the currently playing track.
  • /queue View the current music queue.
  • /stop Stop playback and disconnect from voice.
